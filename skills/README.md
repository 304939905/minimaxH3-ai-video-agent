# Skills 清单

本目录随仓库附带本项目实际使用的 8 个 Skill。它们分为主产线和实验产线，来源与授权状态不同。

## 主产线

| Skill | 用途 | 来源与授权 |
| --- | --- | --- |
| `cinematic-director` | 导演、预演、分镜、走位、连续性、声音、剪辑和 QC | MIT，`cinematic-director/LICENSE` |
| `grok-video-director` | Grok Imagine 视频提示词 | 本地安装副本，未附 LICENSE；见 `grok-video-director/SOURCE.md` |
| `h3-prompt-writing` | MiniMax H3 提示词结构 | 本地安装副本，未附 LICENSE；见 `h3-prompt-writing/SOURCE.md` |

## 实验产线 B

| Skill | 版本 | 用途 | 来源与授权 |
| --- | ---: | --- | --- |
| `novel-outline` | 1.2.0 | 小说改编大纲 | 本地安装副本，未附 LICENSE |
| `novel-script` | 1.2.0 | 短剧剧本 | 本地安装副本，未附 LICENSE |
| `novel-storyboard` | 1.3.0 | 分镜与 H3 投产包 | 本地安装副本，未附 LICENSE |
| `novel-art` | 1.2.0 | 场景与道具美术设定 | 本地安装副本，未附 LICENSE |
| `novel-characters` | 1.11.0 | 角色表、角色卡与音色提示词 | 本地安装副本，未附 LICENSE |

实验产线的产出默认是 `experimental`，确认前不进入正式资产或制作上下文。

## 未随仓库附带的全局 Skill

本机 Codex 环境还安装了 `hyperframes`、`media-use`、`video-shotcraft` 等通用 Skill，但它们不属于本项目当前集成清单，也不自动成为项目依赖。需要时请按各自来源单独安装和核验授权。

## 分发边界

除 `cinematic-director` 明确标注 MIT 外，其余 Skill 文件未附 LICENSE、作者或版本授权声明。公开分发、商业使用或二次分发前，请先核对原发布方的授权条件。
