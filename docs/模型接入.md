# 模型接入

本项目在 Codex 环境中开发和使用。仓库只保留工作流、接入约定和展示片段，不绑定任何 API 供应商，也不包含可直接使用的账号、密钥、代理或计费服务。

## MiniMax H3 API

建议自行接入 MiniMax H3 的官方 API，或你选择的兼容服务。需要自行完成：

- 账号注册、密钥申请和权限管理
- 请求格式、模型名、分辨率、时长、画幅和输入素材
- 任务提交、状态查询、等待完成和结果下载
- 错误处理、超时、重试和并发控制
- 价格核对、付费确认和任务记录

本仓库不提供供应商账号、API Key、代理地址、价格承诺或可直接运行的服务配置。

## 本地 H3 模型

如果要在本地调用 H3 模型，需要自行开发这项能力，包括但不限于：

- 模型权重获取、版本管理和存储
- 推理框架、显存/内存调度和精度选择
- 本地服务封装、接口协议、并发和队列
- 输入素材处理、输出编码和文件命名
- 失败重试、日志、任务记录和资源监控

本仓库不包含本地推理代码、模型权重、环境安装脚本或硬件配置说明。

## 生图模型

本仓库不绑定生图平台，也不提供默认生图账号。使用前请自行选择并接入生图模型或服务：

1. 在本地新增适配脚本，提供提交、查询、下载和本地校验入口。
2. 密钥只从环境变量读取，不写入脚本、JSON、日志或仓库。
3. 提供 `-DryRun` 或等价的本地校验，不发送请求、不创建任务、不计费。
4. 付费提交前展示最终提示词、尺寸、参考图、质量、当前价格、预计费用和验收目标。
5. 下载结果后记录任务 ID、模型、参数、费用依据、输出路径和文件哈希。

## 密钥

- 密钥只从 Windows 用户环境变量或当前进程环境变量读取。
- 不写入脚本、JSON、Markdown、日志、截图或 Git 历史。
- 不在命令行参数中直接传递密钥，避免进入 shell 历史。
- 如果密钥可能已经泄露，先撤销并重新生成，再更新环境变量。

## 参考图与对象存储

如果模型服务需要公网参考图，自行准备对象存储，并生成有时效的签名 URL。不要把长期有效的签名链接写进仓库。

## 付费与记录

提交付费任务前，先向使用者展示最终提示词、模型与模式、输入素材、尺寸/时长、当前价格来源、预计费用和验收目标。确认后再提交。

生成成功后记录任务 ID、模型、参数、输入素材、价格依据、预计费用、输出路径、文件大小和 SHA-256。生成成功只证明任务完成；是否采用仍由实际观看和项目验收决定。
