# MiniMax H3 视频模型资料库

> 本资料库保留原始项目内链；部分链接指向不随仓库附带的 XJXZ 生产文件或原始素材，GitHub 上可能无法打开。

这是面向 AI 视频制作协作的可扩展知识库。它记录模型事实、提示词方法、案例与素材关系，以及尚待实测的结论；目标是让后续的模型选择、提示词、分镜与参考素材配置都可追溯。

## 架构

| 层级 | 目录 | 用途 |
|---|---|---|
| 全局规范 | `00-全局规范` | 术语、资料可信度、命名与更新规则 |
| 模型基础 | `01-模型基础` | 模型定位、规格、能力边界 |
| 方法层 | `02-提示词与工作流` | 可直接复用的提示词结构与模式选择 |
| 案例层 | `03-案例库` | 按案例记录目标、素材角色、可迁移方法与风险 |
| 素材层 | `04-素材索引` | 手册素材与案例的映射；不复制素材本体 |
| 验证层 | `05-验证日志` | 我们实际生成后的参数、结果、问题和迭代 |
| 扩展层 | `06-待学习模块` | 尚未学习章节的接口，避免以后重建资料库 |
| 风格 workflow 层 | `07-风格制作工作流` | 独立记录品牌片、纸艺、产品广告等制作流程；不混同模型能力 |

## 信息状态

- **手册已述**：来自本地《🐚MiniMax H3 模型 - 使用手册》；适合直接作为当前工作规则。
- **官方待核/官方已核**：以 MiniMax 官方文档为准，记录在 `01-模型基础/官方资料核验.md`；当前已完成一次官方核验。
- **实测**：只写入 `05-验证日志`，不把未验证推断当成模型事实。
- **案例观察**：只说明一个已存视频或关键帧呈现的现象，不代表稳定能力或成功率。
- **外部分析**：其他 AI 的报告仅作线索；进入资料库前必须经过本项目审计。
