# 模型定位与规格

来源：本地《🐚MiniMax H3 模型 - 使用手册》的一、二章节；状态：手册已述，待以官方资料持续复核。

## 定位

H3 被定位为通用多模态视频模型：将文字、图像、视频、音频置于同一上下文中理解并生成，而非仅处理单一图生视频或文生视频任务。对制作而言，它适合把“角色/场景/动作/镜头/声音”分配给不同输入，再用文字规定它们之间的关系。

## 输出能力

| 项目 | 手册参数 |
|---|---|
| 时长 | 4–15 秒 |
| 帧率 | 24 FPS |
| 声音 | 原生双声道输出 |
| 文生视频/全能参考画幅 | 21:9、16:9、4:3、1:1、3:4、9:16；全能参考可自动判断 |
| 首/尾帧画幅 | 遵循输入图片原始宽高比 |
| 768p | 常见画幅短边 768；21:9 示例为 1536×672 |
| 1440p | 手册推荐；常见画幅短边 1440；21:9 示例为 2976×1248 |

## 输入边界

| 输入 | 限制 |
|---|---|
| 首/尾帧图片 | 0–2 张；256–5760 px；画幅比 5:2–2:5 |
| 全能参考图片 | 最多 9 张；256–5760 px |
| 全能参考视频 | 最多 3 段；每段 2–15 秒；总时长不超过 15 秒；256–5760 px；画幅比 5:2–2:5 |
| 全能参考音频 | 最多 3 段，必须与图像或视频搭配；每段 2–15 秒；总时长不超过 15 秒 |
| 混合输入 | 总数最多 12 个文件 |
| 单文件大小 | 视频 50 MB、图片 30 MB、音频 15 MB；API 请求体 64 MB |
| 支持格式 | 视频 H.264/AVC、H.265/HEVC（内含 AAC/MP3）；图片 JPG/JPEG/PNG/WEBP/HEIC/HEIF；音频 WAV/MP3 |
| 提示词 | 不超过 7000 字符 |

## 制作上的直接含义

- 15 秒是完整成片的上限，因此复杂叙事先拆成镜头段，再在剪辑中组合。
- 多素材并不等于全都上传；每个素材都要有不可替代的角色，否则会引入无效冲突。
- 首尾帧适合连续过渡，不适合希望模型自动添加多次切镜的片段。
- 有明确人物、动作或镜头复刻需求时，优先使用全能参考，而非只靠形容词。
