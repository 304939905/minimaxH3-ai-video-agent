# 官方资料核验

研究卡：[`research/2026-08-06_minimax-h3_official-capability-card.md`](../../research/2026-08-06_minimax-h3_official-capability-card.md)。状态：官方已核（2026-08-06）。

## 与本地手册结合后的关键规则

- H3 支持文生、首/尾帧、参考生成与视频编辑；生成时长为 4–15 秒的整数秒。
- **首/尾帧与参考生成互斥**：同一次 API 请求中，使用 `reference_*` 后不可同时使用 `first_frame` / `last_frame`。创作方案应拆成不同生成策略，不能把两类素材直接堆在一个请求里。
- 每个生成请求都必须有非空 `text`；素材是参考约束，不替代叙事与控制说明。
- 文生需要指定固定画幅，不能使用 `adaptive`；首/尾帧成片画幅由输入图决定。
- 官方当前文档以 **768P → 2K 再生成** 描述高分辨率工作流；本地手册以 768p/1440p 呈现。实际调用前以当前控制台/API 的可选项为准，并记录到验证日志。

## 生产策略

1. 先以 768P 验证叙事、动作、镜头和多素材关系。
2. 成片构图与关系稳定后，再按官方再生成要求提交 `base_video` 生成高分辨率版本。
3. 多参考关系复杂时，先用 H3-Context-IR 获得结构化提示词草案，再人工检查保持项、冲突和禁止项，最后生成视频。
4. API 是异步任务：保存 `task_id`，成功状态为 `succeeded` 时取 `task.content.url`；这些字段适用于未来自动化，不影响手工网页端创作。
