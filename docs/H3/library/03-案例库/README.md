# 案例库索引

案例按“能力”而不是按手册页序归档。一个案例可以关联多个能力标签，便于以后按任务检索。

## 现有标签（来自手册第一、二、四部分）

- 商业叙事：品牌片、影视预告、时尚片、电商、产品演示。
- 视觉包装：PV、MG、动态字体、海报动态化、TouchDesigner 叠加、AR。
- 多模态参考：多素材联合、人物替换、动作参考、运镜参考、音色迁移。
- 声音：原生环境音、对白、音色/歌词约束、节奏卡点。
- 约束类型：文字可读性、角色一致性、动作轨迹、镜头、场景、负面限制。
