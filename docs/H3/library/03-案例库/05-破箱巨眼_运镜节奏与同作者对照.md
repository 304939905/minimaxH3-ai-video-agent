## 提示词的新增价值

仍采用总时长及一镜到底、画面质量、氛围、第一帧、三处场景、连续运镜、声音的结构。三处空间为水箱厅、下层管廊、高位平台，分别交代环境、出入口、人物动作、预告和并行事件。

与上一组相比，这组更明确设计：

1. **摄影机高度变化。** 从贴地仰角后拉升到半高俯角以揭示大厅，再降回低位追随人物，随后沿梯井跟升。高度改变服务空间信息与人物处境。
2. **观看对象交接。** 水箱破口、逃跑者、控制台操作、面罩反应、回看水箱，形成明确的注意力顺序。重要动作与反应各有预定观察位置。
3. **速度与停顿。** 急速后拉、疾跟、急刹、横移、末尾震颤分别对应冲击、逃亡、发现堵路、寻找出路、遭到打击。文案不只规定移动路线，也规定运动状态的改变。
4. **人物与威胁同框。** 文案要求巨眼占据画面上半部，与人物仰视侧脸同框；目的是同时看清威胁尺度和人物反应。实际是否保留侧脸必须另验。
5. **声音按事件进入。** 声音段逐项绑定破玻璃、按钮、锁止、攀梯、砸护栏；结尾主重击截停，环境声继续。这是值得研究的设计，本次未审听验证。

## 成片对照

时段为抽帧观察的约数，不是严格动作边界。

| 约时段 | 实际所见 | 对照结果 |
|---|---|---|
| 0—1.5秒 | 低位仰看水箱，黄色防护服人物背向镜头，触手冲破玻璃，水与碎片喷出 | 起始威胁成立；以人物背部及水箱为主，没有将单个手掌作为清晰细节特写 |
| 1.5—3秒 | 摄影机侧向跟随人物到控制台，较近距离看到上身与操作 | 行动与摄影机关注对象同步改变；逐个旋钮、按钮、锁止结果未全部核实；未清楚形成文案要求的面罩紧张神态近景 |
| 3—5.5秒 | 人物俯身或倒低后撑起，积水中奔向圆形管廊口，镜头低位跟进 | 水浪与逃生主线成立；完整的回看水箱、整面爆裂再掀翻的因果展示没有按文案逐步展开 |
| 5.5—8秒 | 低位后跟，人物穿过管廊，尽头黄色检修梯进入画面 | 空间过渡及目的地可读；触手扫碎管卡、跨越垮管等细节未清楚呈现 |
| 8—11秒 | 镜头朝上随攀梯调整，人物接近平台，巨眼在上方逐渐露出 | 仰角、垂直空间与威胁揭示有效；巨眼在攀梯中即出现，早于文案的翻上平台、冲刺、急刹之后 |
| 11—13.5秒 | 人物接近或到达平台，巨大眼球在人物上方占据大面积，构图相对稳定 | 尺度对比与对峙成立；主要看人物背面，没有清楚实现仰视侧脸同框及护栏侧挪寻路 |
| 13.5—15.19秒 | 眼部附近水浪与粉色物体涌来，碎片飞散，护栏弯曲，人物被遮挡 | 末尾冲击与破坏可见；无法从所查帧序列清楚确认文案指定的触手自上方砸护栏、人物贴栏低头的完整动作 |

不能把“没有清楚观察到”写成绝对不存在。特别短促动作可在抽帧间发生；重要戏剧节点仍应在成片中有足够可读性。

## 同作者两组的共同写法

| 共同项 | 熔岩蟒隙 | 破箱巨眼 | 可迁移意义 |
|---|---|---|---|
| 第一帧即事件 | 巨蟒从熔岩中暴起 | 触手顶破水箱 | 开始即建立关注对象与变化 |
| 三处相连空间 | 桥、坡、洞 | 厅、管廊、平台 | 先有空间连接，再写移动路径 |
| 事件推动运镜 | 扑击触发撤退、逃生触发跟进 | 破箱触发后拉、奔跑触发跟随、攀梯触发仰角跟升 | 每次运动都有内容原因 |
| 尺度对比 | 巨口近处压来、洞口被堵 | 巨眼覆盖人物上方空间 | 通过构图制造压力，少依赖抽象情绪词 |
| 威胁反复接近 | 外部追击延续到洞口 | 破箱后逃亡仍遭巨眼堵截 | 行动暂时改变距离，不消除危机 |
| 15秒多动作 | 救援步骤被压缩 | 反应近景与终场动作被简化 | 高密度设计有吸引力，也需核验关键节点 |

两篇画面质量段基本相同，含窗边光、生活痕迹等通用词。不能由两个结果确认这些词有效；制作时优先保留场景适配的指令。作者的空间与运动写法值得吸收，通用词堆积不宜直接复制。

## 对当前制作的实践准备

本案例支持补充“机位高度、速度变化、何时停住、人物与对象同框关系”的设计检查。它不是人物吃惊反应特写或对白切镜已经稳定执行的证据。

后续单镜准备同时写：

- 开始：景别、摄影机相对位置、高度、朝向。
- 触发：人物看到或听到什么、发生哪个动作。
- 运动：位移、摇摄或升降、速度及变化。
- 构图：谁进入前景，表情是否可读，背景是否还承担信息。
- 停止：在哪里停，留多久读反应，出口状态是什么。

若人物反应是镜头核心，应明确其可见动作与构图终点，并预留时间；不能在同一短镜里让大量追逐和环境变化挤掉它。可在后续已授权制作中用简单镜头试验，不在本次学习中直接提交付费任务或替换正式分镜。
