## 这一组的新价值

作者仍先写场景、出入口与事件，再写摄影机连续路径。这次不再主要依赖追逐，而以灯龙活化、少女送火、水巷腾跃、绕塔盘升、落地协作、灯焰升起组织奇观与完成感。

1. **观看距离随任务切换。** 展示龙与灯阵的空间后，靠近少女和火种；展示越桥、盘升的整体轨迹后，再回到落地送火的动作关系。人物、动作与环境各有承担信息的时刻。
2. **注意力有接力对象。** 龙眼、龙首、鳞灯、少女、火种、灯塔、协作人物、最终灯海，把观众关注逐步向完成仪式推进。
3. **仰俯角承担信息。** 水面段需要看龙和水巷位置，腾跃与盘升需要看向上运动弧线；不是只给整片一个固定角度。
4. **灯光既是结果，也改变画面。** 文案写火种接近灯芯、灯亮、光照到少女脸上、随后扩大到灯海。可学习“动作改变环境，环境变化映照人物”的写法。
5. **预先到位。** 摄影机先绕到主灯台附近等待少女落下，可避免一直跟在背后，把将发生的重要动作提前安排到可读构图内。

这些为设计方法；不能把所有提示词规定的路径都视为成片已实现。

第三组表明，同一套“空间连接＋事件驱动摄影机”的写法可以用于不同情绪目标。它的学习意义不在于要求所有片段都高速运动或巨物压迫，而在于安排各阶段观众看什么、看多近、为什么移动。

## 对后续提示词的补充

**先确定每个节拍的信息，再确定景别与运动。** 动作细节需要较近画面；空间关系与大幅运动需要较宽画面；关键反应需要表情可读及足够停顿。景别变化应让观众获得新的信息。

特别补充环境与道具的三阶段状态：

- 变化前是什么样，是否允许亮、开、露出？
- 哪个动作触发变化，观众怎样看清接触或操作？
- 变化后是什么样，人物如何察觉或回应？

示例仅供讨论、尚未试验：

> 中景交代人物与桌面。玄鉴起初保持无发光状态；布被揭开后，镜头顺着手部动作靠近，确认玄鉴表面与月晕。接着通过另一个独立反应近景，看清人物目光停住及脸上淡白反光；在反应读清后，再回到较宽画面交代其他人的反应。

这属于多镜组合，不能写成一完整镜头；若坚持长镜头，应改为连续且可实现的位移、摇摄与构图转换。它不改变EP03采用片段，也不视为新正式分镜。
