# 商用级多场景：案例观察索引

来源：手册第三章 1.x 对应视频；本地素材映射记录为 37 条视频。

## 可检索方向

- 品牌片、广告、电商与产品演示；
- PV、MG、动态字体、海报动态化；
- 游戏菜单、UI、影视预告、剧情氛围；
- 手绘、黏土、CG、武侠、悬疑等视觉风格；
- 横版与竖版的构图、标题和节奏参考。

## 可迁移的观察方法

1. 先拆“主体、空间、主动作、镜头、声音、文字”六个维度；
2. 将画面风格词落到材质、配色、光线、构图和剪辑节奏，而非只写风格名称；
3. 把片内文字作为单独验收项；若是商业必须准确的文字，预留后期方案；
4. 只将这些视频用作视觉与分镜参考，不把单支样例称为 H3 的稳定能力。

## 后续卡片字段

每个重点参考可按：视频文件名、目标风格、镜头节奏、主色/材质、声音策略、可借鉴提示词语言、风险项建立独立卡片。
