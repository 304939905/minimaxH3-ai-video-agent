# 案例证据等级与使用方式

素材根目录：`D:\Desktop\xuexi\minimax H3模型示例视频\h3_videos`

## 等级

| 标签 | 含义 | 可用于什么 |
|---|---|---|
| 手册案例 | 手册展示的任务类型或成片 | 找参考、理解任务方向 |
| 文件已核 | 本地视频存在且可读取 | 素材索引与文件属性 |
| 案例观察 | 从该成片直接看到的画面/声音现象 | 设计参考与验收点 |
| 本项目实测 | 有完整提示词、素材、生成记录和结果 | 可复用项目经验 |

## 不可跨越的边界

- 一支成片不能证明某条提示词一定有效；
- 没有原始输入和完整提示词，不能从成片反推素材角色或模型机制；
- 多案例覆盖同类风格，仍不等于稳定生产能力；
- 音色、文字和角色一致性以实际成片验收为准。
