## 提示词如何组织

顺序为：总时长及一镜到底要求、画面质量、风格氛围、第一帧、三处场景元素、连续运镜轨迹、音乐音效。它不是按多个 Shot 切镜，而是把事件与摄影机路径串成一个长镜头。

场景A石桥、B塌石坡、C贯穿裂隙洞各自包含：地貌、相邻地点连接、人物动作、危险预兆、并行事件。其价值在于先交代空间如何连接，再描述摄影机如何穿过空间。

最有用的具体写法：

1. **起点同时给机位和视向。** 例如贴桥面低位、朝北推进。能回答镜头在哪、面向哪、先看到什么。
2. **移动方向与朝向分别写。** “朝南倒退、面朝北”保留追击者在画面中的关系；不能只用一个“向后”。绝对方位有助于作者组织路径，是否被模型逐项执行未知。
3. **动作触发运镜。** 怪物扑近触发后撤；士兵视线引导摇摄；进入洞口触发跟进；攻击线路触发侧让。每次运动都有关注对象与目的。
4. **写构图变化和终点。** 巨口占满前景、人物进入近处、洞口天光收窄、巨头堵住洞口。这比单写“紧张”“震撼”更容易形成可核验的画面目标。
5. **前后景同时有事件。** 近处士兵逃生，后方巨蟒追来；洞内是避让，洞外是威胁。运动改变两者的相对尺度和可见程度。
6. **结束状态明确。** 人物退到洞内、洞口仍被威胁封住；结尾要求截停而非渐隐。其声音截停效果本次未直接听取。

## 画面实际兑现情况

下列时段是抽帧观察的约数，不是原提示词时码或严格动作边界。

| 约时段 | 实际画面与摄影机趋势 | 兑现判断 |
|---|---|---|
| 0—1.5秒 | 面向桥面与熔岩，巨蟒昂起扑到近处，头口迅速占据画面 | 扑近、尺度压迫明确；不能据此断言首帧机位高度与两米尺度精准执行 |
| 1.5—4秒 | 摄影机后撤并侧向移动，巨头缩小，桥面、人潮和侧方坡面逐渐进入画面 | 镜头将注意力从巨物转向逃亡人群，空间揭示成立 |
| 4—6.5秒 | 近处两名士兵出现扶持动作，巨蟒从后方逼近，人物俯身向洞口移动 | 追击与扶持逃生成立；没有清楚展开“被石板压住、撬石、拖出”的完整救援动作 |
| 6.5—9秒 | 镜头进入狭窄岩洞，近处岩壁掠过，外部亮口保留在纵深中 | 连续进入狭窄空间的观感成立；原文规定的南北方位与绕行路径不能仅据成片确认 |
| 9—12秒 | 两人低伏于洞内，摄影机位置与距离继续调整，洞口外的巨头逐渐清楚 | 近处人物与远处威胁形成层次；视向变化是否严格符合设计尚未核实 |
| 12—15.12秒 | 巨头占据洞口并张口，两人贴近岩壁避让 | 洞口封堵与无路可退的视觉压力成立；多次獠牙横扫、火山弹及两端撞壁等细节未逐项确认 |

整体有连续移动的观感；抽帧观察不能证明真正无剪切、无隐藏过渡或空间完全自洽。景别与主体尺度的变化，来自主体运动和摄影机运动共同作用，不能将巨口变大全部算作镜头推近。

## 学到的核心方法

**事件变化、注意力变化、摄影机响应、构图结果应连着写。**

可以复用的写作句式：

> 镜头从【起始景别、机位高度、相对位置】开始，面向【关注对象】。当【可见动作或新信息】发生，镜头以【速度与运动方式】移动，同时【保持或改变朝向】，从【起始构图】发展到【结束构图】，使【关键表情、物件或空间关系】成为画面重点。结束时【停止点与留白】。

这是学习建议，不是接口固定字段、用户定稿或保证成功的模板。实际提交仍按本项目中文规则、模式、素材绑定及结构化字段整理。

## 对EP03短板的针对性补足

此前常把“固定双人中景”作为安全默认，再用动作和对白填满整镜。此案例说明，同一个完整镜头内也能连续改变关注对象、观看距离与前后景关系；一任务一完整镜头不要求摄影机静止或景别恒定。

后续准备镜头时，应先回答：

- 起始让观众看谁、看多远？
- 哪个动作或信息值得镜头改变？
- 是人物靠近、摄影机移动，还是切到另一独立镜头？
- 变化之后，观众必须看清什么？
- 哪里停住，让反应有时间被读到？

供讨论的虚构写法示范，不写入正式剧本：

> 双人中景开始，两兄弟望向画外桌面。长湖先带惊喜；听到父亲画外说“是福是祸”时，他收住笑意，目光转向父亲。镜头此时缓慢推近并轻微调整构图，结束为长湖单人近景，通崖退到画缘。保留半秒停顿，看清长湖从惊喜转为担忧。

该方案存在双人构图调整、脸与口型稳定风险，尚未生成验证。它展示“信息触发推近”，不意味着所有对白都应推近。突然反应也可用独立近景切入；本案例没有提供反应特写剪切的实证。
