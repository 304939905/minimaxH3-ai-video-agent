# 精准编辑：案例观察索引

来源：手册第三章 3.x 对应视频；本地素材映射记录为 21 条视频。

## 覆盖方向

- 角色/物体的替换、增加和删除；
- 背景、局部景色和光影调整；
- 台词、文字、品牌元素与多目标编辑；
- 时间递进式视觉效果。

## 编辑提示词骨架

```text
原视频：说明它承担时空骨架。
变化项：逐项写“把 X 改为 Y”。
保持项：人物/动作/构图/镜头/其他对象哪些不变。
时间过程：何时开始变化、何时完成。
文字与声音：给精确原文，并单独写验收目标。
```

## 验收重点

- 每个变化项是否出现；
- 每个保持项是否被意外重生成；
- 首帧、中段、末帧是否符合时间过程；
- 文字是否可读，声音是否与目标一致；
- 单案例达到目标仅记为案例观察，后续需重复生成确认。
