# H3 提示词框架

来源：手册四「如何更好地使用 H3」。原则：少用需要意会的比喻，多写可见、可听、可执行的画面指令。

## 标准结构

1. **参考素材说明**：逐个注明 `@图片1/@视频1/@音频1` 的角色与保持项。
2. **核心创意**：用一句话锁定主体、地点、事件、题材/风格与特殊镜头。
3. **画面过程**：以 Shot 或时间段写景别、动作、运镜、台词、音效、切镜方式。
4. **整体要求**：贯穿全片的视觉、剪辑、声音、文字和一致性规则。
5. **限制项**：明确不要出现的元素；不想要配乐时写 `非叙事性音乐：N/A`。

## 可复制骨架

```text
【参考素材说明】
@图片1：人物参考。保持脸、发型、服装轮廓与气质。
@视频1：动作参考。只复用动作节奏和运动轨迹。
@音频1：音色/节奏参考；对白原文为：“……”。

【核心创意】
[主体] 在 [地点] 完成 [事件]；[题材/风格]；[画幅、时长、镜头方式]。

【画面过程】
Shot 1：景别 + 画面内容 + 动作 + 运镜 + 台词/环境音 + 转场。
Shot 2：……

【整体要求】
保持项：……；文字原文：“……”；剪辑：……；声音：……
【限制项】
不要……；非叙事性音乐：N/A（如需要）。
```

## 镜头与台词规则

- 每个镜头写清景别、具体主体、镜内运镜和声音；跨镜头角色要指明是前一镜的哪位角色。
- 台词长度必须与镜头时长相称。跨镜台词明确写“接着上个 Shot 继续说”；可描述 J-cut/L-cut 与画内/画外音的转换。
- 不要把“一镜到底”与多分镜结构混写。要一镜到底时，写连续事件、连续运动和连续声音，而不是 `Shot 1/2/3`。
- 对“环绕镜头”优先写可执行的横移与摇摄组合，如 `truck left + pan right`，而不是仅写“环绕”。

## 运镜与景别的具体书写（2026-10-02案例学习）

依据：[熔岩蟒隙提示词与成片对照](../03-案例库/04-熔岩蟒隙_运镜与景别学习.md)。以下是待后续项目实践的方法，不是已证实的模型稳定能力。

- 连着写：起始景别与机位、触发镜头变化的事件、运动方向与朝向、速度、结束构图、停止点。
- 移动方向与看向哪里分别说明；优先用可见人物、桌边、洞口等相对位置建立空间锚点。
- 写清主体如何进入或离开前景、重要表情最终占多大画幅、背景是否仍需可读。
- 运镜必须有关注对象和叙事目的；固定机位也应是明确选择，不能成为每镜默认。
- 一完整镜头内可以有连续景别变化；突然切到反应特写属于另一个镜头，应另作设计。
- 主体靠近也会改变画面尺度；审片时区分主体运动、摄影机运动与剪切。
- 复杂路径应检查动作密度及实际兑现，防止短时长把重要因果压缩掉。

补充依据：[破箱巨眼及同作者对照](../03-案例库/05-破箱巨眼_运镜节奏与同作者对照.md)。写运镜时补齐摄影机高度、速度如何变化、哪里停住；写人物与对象同框时明确表情是否可见。需要强调的反应应有独立时间，不能仅写入高密度动作串便认为已经执行。两个案例可用于归纳作者重复写法，仍不能证明模型稳定能力。

第三组补充：[灯龙上灯](../03-案例库/06-灯龙上灯_景别递进与状态因果.md)。按信息需要安排人物动作的较近构图和展示空间、运动轨迹的较宽构图；每次景别变化都应增加信息。对于点亮、揭开、开启等动作，分写变化前状态、可见触发、变化后状态及人物回应；审片检查是否过早亮起或省略关键接触。摄影机也可预先到重要动作位置等待主体进入，不必始终追随背面。

## 关注对象、剪切关系与特殊效果（2026-10-02教学学习）

依据：[六种镜头教学深度学习](../03-案例库/07-六种镜头教学_适用性初审.md)。标有“网络素材”的画面按用户说明作为实拍范例；作者展示的AI案例模型未知。这是可迁移的镜头方法，不是H3稳定能力结论。

- 先确定当前要观众看谁、看什么，再选择景别、移动或剪切。对白可先建立位置，再看表达、回应和变化结果；不要默认每句都保留多人中景，也不要机械轮流切人。
- 惊讶等心理变化分写刺激、可见反应、反应停顿。是否用特写取决于需要读什么；静止特写同样可以表达情绪。
- 正反打写明人物相对位置、视线方向、摄影机处于人物连线哪一侧及切点；前景肩膀不能替代连续性说明。人物与其所见物件之间的切换另标为视线匹配，不混同两人正反打。
- 保持当前正式产线一任务一完整镜头规则：多镜对白先分开准备，再剪辑；不要在一镜到底请求中写“切到反应特写”。
- 跟拍写起始相对位置、机位高度、距离、出入口和转角、终点；看正脸与全程背拍冲突时先解决。到终点后给镜头和人物一个收束。
- 普通推近与滑动变焦分开：前者可由近景到特写；后者需要前后位移配合反向变焦，典型主体尺度近似稳定、背景透视变化。仅保持人物居中或背景变糊不算后者完成。
- 慢门外观、慢动作、子弹时间分开写。指定哪些对象清楚、哪些拖影、哪些近乎停滞，以及摄影机是否移动；拖影与真实运动方向需匹配。
- FPV写连续空间路径、近处掠过物、高低与转向、速度变化和最终落点；不要仅堆“高速、震撼、电影级”。
- 起止构图与停止点必须可观察。先检查术语和具体动作是否冲突，再逐项对照成片；未展示的终点不能默认为完成。

优先后续练习：对白反打与反应、普通推近、简单跟拍；特殊效果单独验证。教学中的英文缩写可保留，实际H3提示词描述仍用中文。详细练习段落、证据与验收条件见案例主文档；尚未提交生成，不覆盖正式分镜。

音轨补学修订：该教学完整口述已通过本地识别并与字幕核对，来源和原始转写见案例主文档。长镜头另写沿途新增的空间与人物关系信息；反打按话语影响对方的时刻安排，不机械逐句交换镜头。重要动作或反应需要足够观看时间，具体长短随内容决定。比较运镜效果时尽量保持场景、光线、人物与表演一致，不能把同时改变多项条件的开场示例当作“差异全由运镜造成”的证据。机器转写不等于直接听觉审听；用户明确本次音频目标为理解口述教学，不把音色、音乐、混音评价列为必做项。

继续学习补充（同日，切点逐帧核对及前三组对照）：

- 近景反应除景别外，写清脸的朝向、关键面部是否被肩膀或面罩遮挡、刺激后的可见变化及观看时间。推近到背影或反光面罩，不能仅凭距离便认为已经交代情绪。
- 手部特写需同时交代手、目标物和操作前后状态；过近导致目标出框时，扩大构图或另设结果镜头。
- 按信息目的选择方式：切换关注人物可用剪切；连续体验空间或逐渐发现可用移动；读反应、动作结果可稳定停留。这是待实践的方法建议，不要求每段都使用运镜。
- 摄影机停住后，人物仍保留自然呼吸、视线及动作收束；镜头稳定不等于演员冻结。
- 教学办公室样例的四镜实际持续约0.90、2.67、2.93、2.17秒，详见主文档逐帧证据。它们属于剪好的教学片段，不能当作原始生成时长或通用节奏标准；作者教学旁白也不能当作样例角色的原始对白。

## 首次本项目实践：S27受惊与推近（2026-10-04）

实片、中文提示词、同长对比及主线程结论见[S27单片段试点记录](../../XJXZ/第二至十章动画/EP04制作准备/制作记录/学习试点/S27_受惊与推近/试点方案与对比标准.md)。同首帧、同模型与请求参数，仅一次新候选；表演和镜头同时修改，属于案例观察，不证明稳定能力。

- 明确刺激、反应前后状态和可见眉眼/嘴/身体变化，脸须可读；本例受惊明显强于旧版皱眉疑惑，身体后收仍弱。
- 按观看对象决定景别和切换；新版反应后构图收紧并停住更有效，但空间视差不足以确认真实机位推进。静止特写仍是有效选择。
- 时间标记只作目标，审片按实际变化选段；本例反应约1.25秒才明显，晚于提示词要求，后半持续张嘴瞪眼也需裁掉冗余。
- 相邻镜头同时检查刺激、视线和状态承接；本例后段视线抬高，未完全守住右下眼线。同长、原速、相同前后镜头对比，避免把延长或变速当进步。

后续新集按“刺激与状态、可见表演、观看对象与景别、运动起止与视线”逐镜设计并实片验收，不把同一种受惊表情或快推复制到所有情绪。

## 人工剪辑参与的素材设计（2026-10-05）

用户明确后续会通过人工剪辑优化节奏，制作时酌情考虑该环节。分工以[人工剪辑协作规则](../../XJXZ/创作资料库/00_治理/人工剪辑协作规则.md)为准；[EP05候选稿](../../XJXZ/第二至十章动画/EP05制作准备/优化稿_v0.1/README.md)为首次文本应用，尚未生成。

提示词描述完整动作/表演与自然头尾，剪辑交接另写不可丢内容、同场覆盖对象和建议切点。字幕、时间卡、音乐与最终转场不烘焙进生成素材；对白完整而不重复，反应镜先留可读倾听状态。头尾余量和时间标记只作规划，不能为了后期空间接受关键表演缺失。

## 官方结构化改写格式（可选）

来源：已安装的 `h3-prompt-writing` skill。它提供结构化改写方法，不取代上面的网页端中文骨架。该Skill原版建议英文描述；本项目按用户语言规则保留固定字段、标签与时间格式，画面、动作、声音、对白和可见文字描述仍使用中文。

### 基础生成结构

按顺序写三段：

1. `integrated_multimodal_description`：沿时间线写画面、动作、镜头、说话人、对白和画内声音；
2. `overall_soundscape`：环境声、动作声与非语言人声；
3. `non_diegetic_music`：只面向观众的背景音乐。无背景音乐时可写 `N/A`。

### 参考/编辑结构

需要细化素材引用和保持关系时，按顺序使用：

1. `subject_definitions`
2. `summary`
3. `retention_analysis`
4. `detailed_description`
5. `overall_soundscape`
6. `non_diegetic_music`

参考标签包含 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>`。它们与网页端 `@图片/@视频/@音频` 的**语义可映射，但不是同一语法**。

### 适用边界

- 结构化格式有助于把素材、保持项、镜头和声音拆清楚；
- 它不是网页端唯一允许的格式，也不能保证文字、角色或编辑结果必然稳定；
- 对话原文、屏内文字和保持项仍应明确写出，并在成片中验收。
