# 模式选择与素材分工

## 三类入口

| 目标 | 选择 | 写法关键 |
|---|---|---|
| 融合人物、动作、场景、音乐等多源约束 | 全能参考/多模态参考 | 每份输入标明角色：锁脸、锁动作、场景、节奏、音色、运镜或编辑对象 |
| 让一个画面动起来 | 图生视频（1 图） | 明确该图是首帧；描述后续动作、光影、镜头与声音 |
| 从 A 画面自然走到 B 画面 | 首尾帧（2 图） | 两图是连续边界；H3 补中间动作、光影和声音，默认不自动增加切镜 |
| 没有可用素材、需要从概念开始 | 纯文生视频 | 主体外观、场景细节、动作、景别层次、声音和风格写得更具体 |

## 素材角色分配表

| 需求 | 优先素材 | 提示词措辞 |
|---|---|---|
| 人物身份/造型 | 图片 | `@图片1 是人物参考，保持……` |
| 动作/表演节奏 | 视频 | `@视频1 是动作参考，只复用……` |
| 运镜 | 视频 | `@视频1 是运镜参考，保持……` |
| 场景/材质/色彩 | 图片或视频 | `@图片2 是场景/风格参考，只参考……` |
| 音色/歌词/节奏 | 音频 | `@音频1 是音色参考，原文为：“……”` |
| 需要局部增删改 | 原视频 | 先声明编辑对象、保持项、允许改变的区域 |

## 常见冲突检查

- 上传素材却未说明用途：补“素材角色 + 保持项”。
- 想要音乐又写“不要 BGM”：改成指定镜头/声音的规则，或移除冲突。
- 要锁脸却没有人物参考：补人物图，不能仅凭文字期待一致。
- 纯文生提示词过短：至少给出主体外观、空间、动作和风格。

## 从案例归纳的验收提醒

以下是现有手册样例的观察，不是稳定性承诺：

- 涉及颜色渐变、时间递进或多目标编辑时，检查首帧、中段和末帧；
- 文字、Logo、小字与复杂动态字幕必须逐帧查看，重要商业文字保留后期合成方案；
- 涉及人物、背景、光影的编辑，要分别验收变化项和保持项，避免只看主要目标；
- 音色相似度、台词准确性和口型同步不能仅凭画面判断，需要听检或转写辅助。
