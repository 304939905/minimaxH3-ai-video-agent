# 资料规则与术语

## 核心术语

- **素材角色**：一份输入在生成中的唯一职责，例如人物、动作、运镜、场景、风格、音色、节奏或编辑对象。
- **保持项**：必须延续的身份、构图、文字、动作、镜头或声音特征。
- **变化项**：允许模型生成或改写的部分。
- **案例卡**：一个可复查的制作样本，记录输入、提示词结构、输出与可迁移结论。
- **实测结论**：在指定版本、参数和素材下复现过的结果；不得与手册事实混写。
- **案例观察**：从已存成品视频、关键帧或转写中直接看到的现象；不能推导模型稳定性或因果。
- **制作 workflow**：面向某类视频成片的策划、素材、分镜与验收流程；不等同于模型功能。

## 入库规则

1. 每条模型事实写明来源与状态；时效性强的事实优先以官方文档复核。
2. 每个视频素材只保存路径、文件名、来源章节和角色，不复制视频到资料库。
3. 提示词不按“好看词汇”分类，而按可控维度分类：主体、空间、动作、镜头、声音、文字、限制条件。
4. 未验证的经验写入验证日志或待验证清单，不能升级为默认规则。
5. 新学习第三章时，将编辑能力加入 `01-模型基础`、具体案例加入 `03-案例库`、实测写入 `05-验证日志`；不改动现有目录结构。
6. 其他 AI 的内容必须先写入 `handoff` 审计文件，再按“官方规则 / 案例观察 / 待验证”三类导入。
7. 只有同一条件下有可追溯的重复生成记录，案例观察才可升级为本项目经验。
