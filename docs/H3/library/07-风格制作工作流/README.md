# 风格制作 workflow

本目录记录面向具体成片类型的制作流程，例如品牌宣传、极简产品广告、纸艺讲解、手绘实拍和 3D 动画。

## 与模型能力的边界

- workflow 解决“需要哪些素材、怎样拆分镜、何时确认、怎样验收”；
- 它不是 MiniMax H3 的能力承诺；
- 只有官方 `h3-prompt-writing` 的字段与写法属于 H3 提示词结构资料；
- 每种风格 workflow 应在实际项目中记录所用模型、素材和结果。
