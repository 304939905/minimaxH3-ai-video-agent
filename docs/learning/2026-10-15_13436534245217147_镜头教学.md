## 应学的方法

### 1. 前景既交代空间，也交代关系

腿部框景、过腰、过肩都在回答“观众站在谁这边看另一个人”。它们的差别不只是高度：腿框限制观看通道；腰部可突出手和道具；肩背把对面人物与前景人物联系起来。

准备镜头时写清：前景是谁的哪一部分；真正要读清的主体是谁；二者距离；前景遮挡多少；手或道具何时进入主要动作。构图要保留主体眼睛及关键动作的读取空间。

### 2. 绕拍要揭示此前看不见的东西

“反向包抄”段的可学点是从人物背后逐步见到正脸和另一人；“环绕”段的可学点是四周来袭者轮流进入视野。移动新增信息，才有明确叙事作用。

具体路径应有起点、经过位置、关注对象与终点；人物转身、枪口转向和摄影机位移分别约束。不要把人物自转、背景整体旋转当成绕拍成功。遮挡处要额外核查身份、持物、站位及环境锚点有没有跳变。

### 3. 焦点是一种镜头内部的信息交接

车盖装置段与丧尸肩背段都能看到前后清晰度互换。同样的人物位置和画面，观众注意力可以改变。后者不是单纯“背景更虚、画面更电影”，而是让指定目标在指定时刻成为主要可读对象。

提示词要写起始焦点、触发事件、焦点移向、两者的清晰度交接及终点停留。要区分焦点距离变化与焦距变化；本片没有足够参数反推出镜头焦距、光圈、拉焦装置或摄影机型号。

### 4. 动作前让观众认识关键物件

装置先获得清楚的局部画面，后面再出现拿取、展示、操作和爆炸。可迁移的是先建立辨识，再交代动作及结果。迁移到别的故事时，道具必须已有叙事职责；不要为了炫技新增无用物件。

### 5. 同一场景示范多种手段，降低比较负担

蓝衬衫、绿衬衫、黄色发夹、海岸、废墟及强日光形成重复锚点，使不同手段更容易比较。它不是受控实验：动作、人物数量、构图等也同时改变，不能量化哪一种手段“更高级”。武器等元素在不同示范段间有变化，不当作一段严密连续战斗来验收。

## 教学包装与观看节奏

**先演示，再命名，再说用途。** 开场立即给出腿部框景；后续取枪、绕拍、来袭者入画和焦点变化都在讲解期间实际发生。口述不只报术语，也配“道具与人物关联”“局势反转”“发现线索”等用途。可迁移到我们的教学或说明短片：画面本身应让机制可见，文字补充命名与用途。

**文字有两级。** 巨大的红色粗字标记手段，小号白字承接口述；红字与蓝天、海水及蓝衬衫形成明显区别。部分大字被人物遮住，呈现嵌入画面纵深的观感；具体制作方法未知。正式讲故事时是否保留教学大字要另选，不能把参考片的所有包装照搬进剧情。

**时长服从机制。** 23.9—31.9秒的环绕约8秒，需让正面、侧面、背面及外围威胁依次可读；31.9—33.97秒的道具调焦约2.07秒，依靠一次清晰交接完成示范。不能由此推导通用最佳秒数，但可以检查“本镜需要读到什么变化，是否已经读完”。结尾先问观众，再给操作特写与爆炸结果，让互动口述仍伴随行动；没有留存数据，不能声称这必然提高完播率。

```text

```

**由道具转向反应：**

```text
单个完整镜头，摄影机固定。前景桌面上的信物清楚，后方人物面部模糊但轮廓可辨，两者同时留在画面内。人物认出信物，手先停住，随后焦点平稳从信物移到人物眼睛；信物逐渐虚化，人物眼睛逐渐清楚。焦点到达后，读到人物抬眼并压住惊讶的反应，最后停留。人物与信物不改变位置，不用整幅画面模糊或换镜替代焦点交接。
```

**俯拍交代关系：**

```text
单个完整镜头，近垂直俯拍，摄影机固定。两人在地面中央偏左站定，第三人从画面右侧沿清楚可见的空地接近；三人始终同框，地面纹路作为固定参照。第三人接近到约定位置后停下，画面保留三人的距离与朝向。人物不瞬移，地面不旋转，不要求在这个距离读清面部表情。
```

## 素材、模型与验收

- 跨镜复用优先锁定核心人物、叙事道具和空间锚点。原理沿用[资产分级与最小化规则](资产分级与最小化规则.md)，不为每个临时背景人物制作独立角色卡。
- 关系镜头需要清楚的起始构图；绕拍另需空间侧面及背面锚点；调焦练习需要前后目标同时在画面，单独两张脸部大头图不能独立定义纵深关系。
- 模型选择按任务测试：是否保留前景人物和视线、能否沿明确弧线改变视点、能否实现前后清晰度交接。当前没有本片的模型来源和项目实测，不能给H3、Grok或其他模型排序，也不虚构成功率与成本。
- 剪辑可选择信息进入和退出的时刻，不能补造未生成的绕拍空间、人物反应或道具操作。调焦在后期做时需要可靠的深度或遮罩，不能简单用整幅模糊冒充。
- 建议最先练过肩反应和固定构图内的焦点交接；完整环绕涉及更多身份、空间及遮挡连续性。这个优先级是助手制作建议，不是模型能力结论。

| 手段 | 最小验收问题 |
|---|---|
| 过腰、过肩 | 前景与主体属于明确的两人吗；眼神与关键手部可读吗；有无无意换边或持物跳变 |
| 绕拍揭示 | 新人物是否从遮挡后连续显露；摄影机路径与人物动作能否区分；最后有无可读构图 |
| 俯拍 | 三人位置、朝向、接近方向是否连续；宽构图是否确实让关系更清楚 |
| 环绕 | 人脸、服装、持物、背景锚点与外围人物位置是否在绕行及遮挡后接得上 |
| 焦点交接 | 起始与结束清楚的对象是否不同；二者位置是否保留；焦点到达后是否有可读内容 |
| 道具因果 | 先前建立的物件能否被识别；拿取和操作有无缺步；结果是否清楚且与剧情相符 |
