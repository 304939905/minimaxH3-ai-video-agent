# AI 视频参考库

> 本目录是从参考视频提炼的学习成果，不包含原视频素材；模型来源未知时已标注。案例只证明样例现象，不代表稳定能力。

这里保存从参考视频中提炼的、可迁移到 AI 视频生产的规律；不保存或复刻原视频素材。

来源与改写说明见 `SOURCE.md`。

部分笔记中的相对链接指向本地原始视频、抽帧、ASR 证据或生产目录；这些原始材料不随仓库附带，GitHub 上可能无法打开。正文结论、来源登记和文件哈希仍保留。

每条记录至少包含：来源与授权状态、可观察的视觉/运动规律、可复用提示词结构、适合的模型能力、以及不可从单条样本推断的部分。
