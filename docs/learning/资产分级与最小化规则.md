# AI视频资产分级与最小化规则

## 核心原则

资产的目的，是锁定跨镜头、跨场景或跨轮生成必须保持一致的身份与美术信息，不是把画面里出现的每个元素都制作成角色卡或素材。

先问两个问题：

1. 这个元素是否会在多个镜头反复出现，并且观众需要认出“它还是同一个”？
2. 如果模型在下一镜改变它的外形、比例或风格，会不会破坏叙事或连续性？

只要其中一个答案明确为“是”，才优先建立资产。两个答案都为“否”，原则上直接按镜头生成。

## 三级资产制度

### A级：必须建立资产

满足任一条件：

- 核心人物、核心物件、核心生物；
- 跨多个镜头或章节反复出现；
- 五官、服装、结构、纹样或比例变化会破坏身份；
- 同时承担剧情、情绪或世界观信息；
- 后续提示词和首帧需要反复引用。

常见交付：角色卡、标准形象、关键角度、服装规则、尺寸关系、声音卡、素材编号。

### B级：只做场景或视觉规则样张

适合：

- 多镜头复用的主要场景；
- 特定主观视野或特效语言；
- 需要统一光线、空间结构或视觉规则，但不需要完整资产包的内容。

只制作当前镜头真正需要的母版、首帧或样张，不提前制作三视图、全套状态和后续章节内容。

### C级：镜头内临时元素

适合：

- 只短暂出现一次或两次；
- 不承担身份识别；
- 外形轻微变化不会影响理解；
- 主要用于环境活力、尺度、转场或氛围。

例如普通鱼蟹、远处飞鸟、舟影、炊烟、流光、水纹、颗粒和普通路人。它们不建立独立资产，只在提示词中约束数量、相对尺寸、方向、位置和动作。

## 升级与降级

- 临时元素如果后来成为反复出现的角色或关键线索，再从C级升级为A级或B级。
- 已经建立的资产如果不再影响身份与连续性，可以停止扩充，不因沉没成本继续制作。
- 一个元素是否建资产由叙事职责决定，不由画面复杂程度决定。

## 与镜间连续性的关系

- 不建独立资产不等于不控制。临时元素仍必须服从镜头衔接合同，例如鱼的运动方向、鸟影进入位置和水纹扩散形状。
- 连续性优先使用上一镜真实尾帧、下一镜首帧和屏幕方向约束，而不是为所有元素建立素材卡。
- 只有需要跨镜头保持身份的元素才反复引用同一资产。

## 执行检查

制作新资产前记录：

- 它服务哪些镜头；
- 哪些特征必须一致；
- 不做资产会造成什么具体风险；
- 最小交付是什么；
- 什么时候可以停止扩充。

如果不能回答“不做资产会破坏什么”，默认不建资产。
